## 项目说明（Description）

本客户端插件为游戏添加了Emoji字体支持，让您既能正常渲染表情符号，也能在聊天栏中快捷插入Emoji。
请注意：仅安装插件的玩家可见完整表情，未安装者将看到***;XXXX;**或空白方框。

This client-side addon adds Emoji font support to the game, allowing you to both render emojis properly and quickly insert them into the chat bar.
Please note: Only players with the addon installed can see the full emojis; those without it will see **;XXXX;** or a blank square instead.
